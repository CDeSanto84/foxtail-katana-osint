# Contributing

Open an issue to discuss a change before starting a large feature. Include the
problem, steps to reproduce it, and the relevant platform/version. Keep examples
synthetic and remove credentials and private application data from reports.

Run the checks in the README before submitting a pull request. Explain the
resulting behavior and any remaining limitations. Preserve third-party licenses
and attribution. AI-assisted contributions are welcome when their behavior is
understood and their validation is documented.
